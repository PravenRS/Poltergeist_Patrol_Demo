# Poltergeist Patrol - web demo

A playable web build of Poltergeist Patrol, a portrait mobile game that mixes a 2048-style merge board
with a tower defense. Swipe the board to merge tiles for points, then spend the points on towers to
stop the ghosts.

Play it: https://pravenrs.github.io/Poltergeist_Patrol_Demo/

This repo only holds the compiled Unity WebGL build (Unity 6000.6.7f1). The game itself is built
separately and the build is republished here when there is a new version.
